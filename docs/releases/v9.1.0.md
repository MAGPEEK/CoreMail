# CoreMail v9.1.0: shared mailboxes over IMAP, full REFERENCES threading, Helm tested on a real cluster

**Image:** `magpeek/coremail-app:9.1.0` · **Helm chart:** 2.0.1 · **Date:** 2026-11-15 · **Predecessor:** v9.0.0

This is a minor release with no breaking changes: you can upgrade from 9.0.0 without changing your configuration. It closes the known limitations of 9.0.0. An independent review covered every change, and each finding was fixed with a regression test.

**Verification:**
- `pnpm -r test`: 2,021 tests passed, 0 failed.
- End to end against the real image: MinIO 135/135 and filesystem 130/130, plus live checks of the new features.
- The Helm chart was installed on a real kind cluster.

## Highlights

- **Shared and delegated mailboxes in IMAP clients** (`Shared/…`, `Other Users/…`):
  - Thunderbird and Apple Mail show them next to your own folders.
  - Full access allows everything. Read-only grants open read-only and refuse writes.
  - The target mailbox's quota applies.
  - Revoking a permission takes effect immediately and closes the open folder.
- **Full RFC 5256 REFERENCES threading:** the References header is now stored, and older messages are indexed in the background. JMAP keeps a reply in its thread even when the direct parent is missing.
- **Recover deleted items in shared and delegated mailboxes** with full access. Restore and purge are audited.
- **Shared mailbox quota** is shown in the webmail.
- **Apple profile on iPhone/iPad** opens directly in Safari's installer, via a single-use ticket.
- **Helm chart tested on a real cluster** with `scripts/k8s-e2e.sh`. It covers Pod Security "restricted", NetworkPolicies, setup, SMTP→IMAP, and upgrade/rollback.
- **Security:**
  - Delegates lose access to the recoverable items of deactivated owners.
  - Backup routes check paths case-sensitively.
  - backup-service applies the same mailbox-data role rule as the gateway.

## Upgrade

```bash
cd /opt/coremail && git pull && docker compose pull && docker compose up -d
```

- **Schema:** the new `Message.references` column is applied automatically, with no data loss.
- **Folder names:** personal folders whose name starts with `Shared/` or `Other Users/` are hidden from IMAP LIST, because those prefixes now name the shared namespaces. Rename such folders in the webmail.
- **New optional settings** (all with safe defaults):
  - `IMAP_NAMESPACE_SHARED`, `IMAP_NAMESPACE_OTHER_USERS`, `IMAP_SHARED_ACCESS_CACHE_MS`
  - `REFERENCES_BACKFILL`, `REFERENCES_LAZY_BUDGET_MS`
  - `SMTP_HOSTNAME` / `POP3_HOSTNAME`, which can now be set from `.env`

## Known limitations

- IMAP shared namespaces were tested against the RFCs and protocol tests, not yet with real Thunderbird or Apple Mail clients.
- The Helm chart was tested on kind. Ingress/cert-manager, cloud load balancers, external datastores and more than one replica remain untested.
- `decode-uri-component` (pulled in through MinIO's query-string) carries an advisory, but the vulnerable path is not used.

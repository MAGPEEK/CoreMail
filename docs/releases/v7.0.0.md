# CoreMail v7.0.0 — Secure by default

**Image:** `magpeek/coremail-app:7.0.0` · **Date:** 2026-11-15 · **Predecessor:** v6.0.0

## Highlights

v7.0.0 finishes the full code review started in v6.0.0. Every remaining finding was fixed,
the whole stack was tested end to end against the real container image (95/95 checks, see
[docs/e2e.md](../e2e.md)), and every fix is covered by automated tests (561 tests).

- **Mail clients are secure by default:** authentication only after TLS on every port,
  app passwords mandatory for users with two-factor authentication, brute-force lockout
  per IP and account on all mail protocols.
- **Web and admin:** hashed, rotating sessions with revocation, hardened MFA (backup codes,
  WebAuthn security keys, encrypted TOTP secrets), role-based admin access, setup token,
  no service crashes on bad requests, no secrets in API responses.
- **Complete messages everywhere:** the original message is always stored; IMAP, POP3 and
  backups deliver it byte-exact with attachments; the web client downloads attachments.
- **New:** OIDC single sign-on, LDAP/AD login and sync, automatic certificate renewal,
  out-of-office replies, real S/MIME verification, full IMAP SEARCH/literals, CalDAV sync
  (REPORT) with recurring events, working quarantine release.
- **Removed:** EWS (web services protocol).

## Breaking changes — please read before upgrading

1. Users with two-factor authentication must use **app passwords** in every mail client
   and phone (IMAP, SMTP, POP3, ActiveSync, CalDAV/CardDAV, JMAP).
2. Ports 143/110/587 accept credentials **only after STARTTLS/STLS**.
3. **EWS is removed** — EWS accounts in macOS Mail or eM Client must switch to IMAP +
   CalDAV/CardDAV, JMAP, or ActiveSync on phones.
4. Behind a reverse proxy set **`TRUST_PROXY`**.
5. New installations need the **setup token** from the container log or `SETUP_TOKEN`.
6. **Admin roles are enforced** per area.
7. Set **`MFA_ENCRYPTION_KEY`** before rotating `JWT_SECRET`/`PEPPER`.
8. **LDAP** requires TLS and a matching `mail` attribute.
9. The **MinIO image** changed to `pgsty/minio` (pinned) because the official image is no
   longer available.

All details: [CHANGELOG.md](../../CHANGELOG.md) → 7.0.0 → Upgrade notes.

## Upgrade

```bash
cd /opt/coremail && docker compose pull && docker compose up -d
```

- Schema changes are applied automatically at startup (the EWS columns are dropped).
- Existing messages are converted to the original-message format on first access.
- Phones using ActiveSync perform one full resync.

## Known limitations

ActiveSync uses the EAS 2.5 body element and answers some optional commands with an empty
response; JMAP caches Basic logins for up to 60 s; the Helm chart is outdated.

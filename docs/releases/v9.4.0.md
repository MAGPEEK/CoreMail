# CoreMail v9.4.0: webmail redesign, MAPI over HTTP, protocol access switches, realtime push, calendar and tasks

**Image:** `magpeek/coremail-app:9.4.0` · **Helm chart:** 2.2.0 · **Date:** 2026-11-18 · **Predecessor:** v9.3.0

This is a minor release: you can upgrade from 9.3.0 without changing your configuration. The schema changes are additive and are applied automatically at start. Independent reviews covered every work package; every finding was fixed with a regression test. Please read the behaviour changes below before you upgrade.

## Highlights

- **MAPI over HTTP for desktop mail programs.** A desktop client with MAPI over HTTP can create a MAPI account against CoreMail (mailbox and address book endpoints, live notifications, Autodiscover). It is **opt-in** (protocol switch `mapi`, off by default), works in **online mode only** (cached mode is not supported yet) and authenticates with **Basic over HTTPS** (no NTLM). Setup guide: [docs/mapi.md](../mapi.md). EWS stays removed.
- **Protocol access switches.** IMAP, POP3, SMTP submission, ActiveSync, JMAP, CalDAV/CardDAV, webmail and MAPI can be switched on or off per server, domain and mailbox; open connections end at once. BCP → Protokolle & Dienste shows access, ports and warnings on one page. Admin API, CLI `coremail protocol`.
- **Webmail policies.** Module switches (calendar, contacts, tasks, notes, rules, app passwords, …), blocked attachment types, upload limit and an external-image policy per server, domain and mailbox.
- **Webmail redesign.** App rail, command bar, compose inline in the reading pane with draft tabs or in its own window, slim compose with a formatting bar, name check, accessibility check, importance and sensitivity, read and delivery receipts.
- **Realtime.** Every change reaches IMAP IDLE, JMAP push and the webmail at once; Web Push for new mail (opt-in); the webmail is installable (PWA).
- **Calendar and tasks.** Recurrence editor, edit or delete one occurrence of a series, scheduling assistant, rooms with conflict check, show-as, reminders; follow-up flags on mail (also over ActiveSync) and the full task form.
- **Mailbox management.** Auto-mapping of shared mailboxes, sent copies for send as / on behalf, per-mailbox mail flow, mailbox access audit.
- **Personal settings that roam** between devices (view, theme, language, region, calendar, reading, compose), several named signatures, sessions list.
- **ActiveSync 12.1 and 14.0** next to 14.1, negotiated per request.
- **Hygiene.** Sender block / allow lists, spoofing settings, DNSBL score weights and the API rate limit are configurable in the BCP.
- **Legacy clients.** Opt-in TLS 1.0/1.1 and an opt-in device relay for scanners and printers.
- **Security.** Certificate private keys are encrypted at rest; an unreadable key no longer turns TLS off on the mail ports.

## Upgrade

```bash
cd /opt/coremail && git pull && docker compose pull && docker compose up -d
```

- **Schema:** additive, applied automatically (new tables `protocol_policies`, `webmail_policies`, `trusted_image_senders`, `user_signatures`, `device_relay_settings`, new nullable or defaulted columns).
- **Recipient limit:** webmail and REST now use the SMTP *max. recipients* setting (default **100**). The webmail used to allow up to 500 recipients per message — raise the setting if you need more.
- **Free/busy:** the free/busy of colleagues is only visible with a calendar share. `/calendar/freebusy` answers `found: false` for addresses outside the caller's own address list.
- **MAPI** is off by default; MAPI clients work in online mode only; NTLM is not offered.
- **App passwords:** switching off the webmail policy module "App-Passwörter" also blocks existing app passwords on all mail protocols. Users with MFA then lose mail-client access until it is switched on again.
- **Other behaviour changes:** the global API rate limit counts per user (3000 per 15 min) instead of 500 per IP; DNSBL "Score" zones now influence the spam score (a message near the Junk threshold may land in Junk); ActiveSync 14.x answers a successful SendMail with an empty body; Autodiscover announces only enabled protocols; IMAP `DELETE` of a mailbox with messages moves them to Trash (refused with `NO [CANNOT]` without a Trash folder).
- **Certificate keys** are encrypted at the first start. Keep `MFA_ENCRYPTION_KEY` (or `JWT_SECRET` + `PEPPER`) in your `.env` backup — without it stored certificate keys cannot be read and the certificates must be issued or uploaded again.
- **Opt-in** (no change until enabled): `mapi` switch, TLS 1.0/1.1, device relay.

## Known limitations

- MAPI: no cached mode, no calendar / contacts over MAPI yet, no NTLM.
- Room booking by mail checks conflicts against the first instance of stored recurring bookings; a colliding occurrence declines the room for the whole series.
- Spanish and Italian webmail show English texts for the new command bars.

# CoreMail v10.4.2: slimmer setup wizard, one-click certificate, restart button

**Image:** `magpeek/coremail-app:10.4.2` · **Helm chart:** 3.4.0 · **Date:** 2026-11-20 · **Predecessor:** v10.4.1

## Highlights

- **Setup wizard in five steps:** token, domain and host name, administrator, back up the secrets (now a download button), done. DNS and certificate moved to the admin panel.
- **Secrets download:** only for the new administrator, only until the wizard is finished (at most 24 hours), recorded in the audit log. Over plain HTTP the wizard asks you to download only in your local network.
- **One-click certificate:** while no trusted certificate covers your host name, the admin panel dashboard offers "Let's-Encrypt-Zertifikat anfordern". It issues the certificate, uses it for the mail protocols and assigns it to HTTPS.
- **Restart button:** BCP → Server & Health → "CoreMail neu starten" restarts the coremail container (about 20–30 seconds); the database, Redis and scanners keep running.

## Update

```bash
curl -fsSLO https://github.com/MAGPEEK/CoreMail/releases/latest/download/docker-compose.yml
docker compose pull && docker compose up -d
```

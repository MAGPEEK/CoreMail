# CoreMail v10.5.0: attack protection, send limits, MFA enforcement

**Image:** `magpeek/coremail-app:10.5.0` · **Helm chart:** 3.5.0 · **Date:** 2026-11-20 · **Predecessor:** v10.4.2

A minor release: existing installations upgrade without configuration changes.

## Highlights

- **Attack protection** (BCP → Schutz → Angriffsschutz): see and unlock locked IPs and accounts, a permanent block list and exceptions for all services, automatic blocking of repeat offenders (escalating, never for shared or private addresses), notification mails to the administrator, and every protocol in the attack dashboard.
- **Victims stay in**: when strangers lock an account, its owner keeps access from known networks and devices.
- **Send limit per account** on every sending path (200 messages / 1000 recipients per hour by default) against misuse of a compromised account.
- **Hardened web server**: timeouts and connection limits against slow and connection-flooding attacks.
- **MFA enforcement**: required for administrators on new installations; optional for all users with a grace period.
- **Local first domain**: the setup wizard starts with `example.local` and a self-signed certificate; add your real domain later and request a certificate with one click.

## Update

```bash
curl -fsSLO https://github.com/MAGPEEK/CoreMail/releases/latest/download/docker-compose.yml
docker compose pull && docker compose up -d
```

Behind a reverse proxy: set `TRUST_PROXY` to the proxy's address so real client addresses are used.

# CoreMail v10.7.0: webmail in three columns

**Image:** `magpeek/coremail-app:10.7.0` · **Helm chart:** 3.7.0 · **Date:** 2026-11-23 · **Predecessor:** v10.6.1

A minor release: existing installations upgrade without configuration changes.

## Highlights

- **New webmail layout**: an app rail on the left and three rounded cards — folders, message list, content. No top bar and no ribbon any more; every action sits in the card it belongs to. No function was removed.
- **List card** with the search, filters, a selection bar for several messages and a status line with the sort order.
- **Content card** with a clear action row for the open message; drafts open as tabs in the same card.
- **Calendar and contacts** with a compact toolbar inside the card.
- **Notifications** behind the bell in the rail: new mails, reminders and calendar shares.
- **New default colour petrol** in webmail and admin panel; a colour set in the branding still wins.

## Update

```bash
curl -fsSLO https://github.com/MAGPEEK/CoreMail/releases/latest/download/docker-compose.yml
docker compose pull && docker compose up -d
```

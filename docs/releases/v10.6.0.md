# CoreMail v10.6.0: MFA policy, passkeys, password reset, self-registration

**Image:** `magpeek/coremail-app:10.6.0` · **Helm chart:** 3.6.0 · **Date:** 2026-11-21 · **Predecessor:** v10.5.0

A minor release: existing installations upgrade without configuration changes.

## Highlights

- **New BCP group "Authentifizierung"** with MFA, Passkeys, password reset, self-registration, SSO and LDAP.
- **MFA policy**: required / optional / off for all users, a rule for administrators and exceptions per user. Administrators without MFA get a dismissible reminder and at most 14 days.
- **Remember device**: skip the second factor on a known browser for 30, 60, 90 or a custom number of days.
- **Passkeys**: sign in without a password using the device's fingerprint, face or PIN, a security key or a phone. Off until an administrator switches it on; needs HTTPS and a host name.
- **Self-service password reset**: a confirmed external recovery address, a second factor for accounts with MFA, administrators excluded by default.
- **Self-registration**: "Konto erstellen" on the sign-in page, off by default, with allowed domains, approval by an administrator and optional invite codes.
- **Setup wizard**: a real domain gets a Let's Encrypt certificate right in the wizard.
- **Attack protection**: the page now refreshes visibly and also shows connection floods and web-login attacks.
- An independent security review of the release; all findings are fixed.

## Update

```bash
curl -fsSLO https://github.com/MAGPEEK/CoreMail/releases/latest/download/docker-compose.yml
docker compose pull && docker compose up -d
```

Note: administrator accounts get password-reset links only after "Auch Konten mit Administratorrolle zulassen" is switched on.

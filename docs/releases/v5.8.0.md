# CoreMail v5.8.0 — Admin-CLI `coremail`, neue Docker-Compose, EWS an MAPI gekoppelt

**Image:** `magpeek/coremail-app:5.8.0` · **Datum:** 2026-10-28 · **Vorgänger:** v5.7.1 (JMAP-Server)

## Highlights

### ⌨️ Admin-CLI `coremail`

Im App-Image steckt jetzt eine Kommandozeile für die tägliche Verwaltung — ohne Browser, skriptbar, mit `--json`:

```bash
alias coremail='docker exec -it coremail coremail'
coremail login -u admin@example.de
coremail user create max@example.de --name "Max Muster" --quota 10GB
coremail shared grant team@example.de max@example.de FULL_ACCESS SEND_AS
coremail connector disable pop3
coremail smtp banner set "mail.example.de ESMTP"
coremail cert letsencrypt --domains mail.example.de --email admin@example.de --services SMTP,IMAP,POP3
```

| Bereich | Funktionen |
|---------|-----------|
| Benutzer | anzeigen, anlegen (mit Postfach), ändern, Passwort setzen, löschen |
| Postfächer | Belegung/Quota, Ordner mit Zählern, Quota setzen, Belegung neu berechnen |
| Shared Mailboxes | anlegen, löschen, Berechtigungen vergeben/entziehen |
| Konnektoren | Status aller Dienste; SMTP/SMTP-Submission/IMAP/POP3 ein/aus, Listener-Ports/Adresse/TLS; JMAP und MAPI/EWS schalten |
| SMTP-Banner | anzeigen, setzen, zurücksetzen |
| Zertifikate | anzeigen, Self-Signed, Let's Encrypt (HTTP-01), aktivieren (HTTPS/Protokolle), erneuern, löschen |

Die CLI nutzt die REST-Admin-API — dieselben Rollen und derselbe Audit-Log wie im BCP. Anmeldung mit Passwort + TOTP, Umgebungsvariablen für Skripte oder fertigem Token. Doku: [docs/cli.md](../cli.md).

### 🐳 Neue `docker-compose.yml`

Auf das Nötigste reduziert und durchgehend erklärt. Fünf Pflichtwerte aus der `.env`, geprüft beim Start:

```
JWT_SECRET · PEPPER · POSTGRES_PASSWORD · REDIS_PASSWORD · MINIO_ROOT_PASSWORD
```

Fehlt einer, bricht `docker compose up` sofort mit Hinweis ab. `bash scripts/setup.sh` erzeugt die `.env` mit Zufallswerten. Interne Service-URLs und -Ports sind aus der Datei verschwunden (Defaults im Image). Alles Weitere — Hostname, Domains, Zertifikate, Konnektoren — wird nach dem Start im BCP oder per CLI eingerichtet.

### 🔒 EWS nur noch zusammen mit MAPI over HTTP

Exchange Web Services war als eigener Outlook-Weg veraltet: Outlook 2024 LTSC und Microsoft 365 sprechen kein Basic-Auth-EWS gegen Fremdserver. EWS bleibt als Begleitprotokoll von MAPI over HTTP erhalten (Frei/Gebucht, Abwesenheit, OAB) und hängt am selben Schalter: BCP → Server → **„MAPI over HTTP + EWS“** (Default aus). Ist er aus, antworten `/EWS/*` und `/OAB/*` mit 404 und Autodiscover nennt kein EWS. Outlook richtet sich dann als IMAP-Konto ein.

## Upgrade

```bash
cd /opt/coremail && docker compose pull coremail && docker compose up -d coremail
```

- Bestehende `.env` bleibt gültig. Wer die neue Compose übernimmt: Pflichtwerte wie oben, der Rest ist optional.
- Outlook-Konten, die bisher über EWS liefen: „MAPI over HTTP + EWS“ im BCP aktivieren oder auf IMAP umstellen.
- Keine Schema-Änderung; kein Datenverlust.

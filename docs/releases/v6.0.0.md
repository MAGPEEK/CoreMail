# CoreMail v6.0.0 — Security & cleanup release

**Image:** `magpeek/coremail-app:6.0.0` · **Date:** 2026-11-14 · **Predecessor:** v5.9.0

## Highlights

CoreMail went through a full code review (clean code, security, business logic and protocol
tests). This release fixes the most severe findings, removes code that did not work and adds
automated tests for every fix (`pnpm -r test`, 113 tests).

- **Security:** bad tokens no longer crash services; refresh tokens are no longer accepted as
  access tokens; JMAP prototype pollution, Bcc leak and delegation scope fixed; stored XSS in
  the Shared Mailbox view fixed; cross-mailbox access via inbox rules and EWS ResolveNames
  closed; SMTP command injection after oversized DATA fixed; input line length capped.
- **Mail delivery:** ActiveSync/EWS sending works again (mail was silently lost); mail from
  desktop mail programs (465/587), rule forwards, ActiveSync and EWS is DKIM-signed; the spam
  filter connection stage (DNSBL, GeoIP, greylisting) runs again; transient errors are no
  longer turned into permanent bounces.
- **IMAP:** `UID FETCH`, `UID STORE` and `STORE` address the right messages; `UID EXPUNGE`.
- **Retention:** counts from delivery time, not from the sender's `Date:` header.
- **Removed:** MAPI over HTTP (did not work with a real desktop client), the unused internal
  `storage-api` service, the PowerShell stub, legacy shared-mailbox routes, dead BCP pages,
  OpenTelemetry modules.

## Breaking changes

- MAPI over HTTP is gone. Desktop clients: set up an IMAP account, calendar/contacts via
  CalDAV/CardDAV.
- The BCP switch is now **"EWS"** (Server page). The stored value is
  unchanged, so an instance that had "MAPI over HTTP + EWS" enabled keeps EWS enabled.
- CLI: `coremail connector … ews` replaces `… mapi` (`mapi` still works, with a warning).
- Removed endpoints: `/mapi/*`, `/PowerShell/`, `POST /api/v1/admin/ems/cmdlet`,
  `/api/v1/admin/mailboxes/shared*`.
- JMAP delegates with only SEND_AS/SEND_ON_BEHALF no longer see the owner's mailbox.

## Upgrade

```bash
cd /opt/coremail && docker compose pull coremail && docker compose up -d coremail
```

- No schema change, no data loss. The existing `.env` remains valid.
- Domains without a DKIM key get one when created from now on; for existing domains open
  BCP → Domains → DKIM once and publish the TXT record if you have not done so yet.

## Known open issues

IMAP literals/SEARCH/STATUS, POP3 rendering from the raw source, JMAP `/changes` after IMAP
flag changes, calendar all-day/recurrence persistence and CalDAV ETags, atomic UID/modSeq
allocation, certificate auto-renewal, quarantine release. MFA is not yet enforced for
IMAP/SMTP/POP3/ActiveSync logins (app passwords recommended).

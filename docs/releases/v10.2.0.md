# CoreMail v10.2.0: Outlook-style webmail shell, search suggestions, message trace details

**Image:** `magpeek/coremail-app:10.2.0` · **Helm chart:** 3.2.0 · **Date:** 2026-11-20 · **Predecessor:** v10.1.0

A minor release: upgrade from 10.1.0 without configuration changes; additive schema changes only.

## Highlights

- **Outlook-style webmail shell.** One simplified ribbon (Start / Ansicht / Hilfe) for mail, calendar and contacts, floating panes on a canvas, optional background pictures (built-in or own upload, organisation default in BCP → Branding), folder favourites, date groups in the message list, "Neue E-Mail" with E-Mail, E-Mail aus Vorlage and Ereignis.
- **Mail templates.** Save, manage and insert personal templates with subject, recipients and body.
- **Search suggestions from the whole mailbox.** While typing, people and messages from every readable folder appear, plus your last searches. A PostgreSQL trigram index keeps search fast and is maintained by the database itself.
- **Growing tables in mail.** Pick the size when inserting; "+" handles on the right and bottom edge add columns and rows; Tab or Enter in the last cell add a row.
- **Calendar "show as".** Busy solid, tentative striped, free outlined, out of office always purple with a dashed border. "Neues Ereignis" opens the event form directly; the scheduling assistant is removed.
- **Message trace details (BCP).** Clicking a message shows what CoreMail did with it (connection, TLS, authentication checks, virus and spam scan, rules, delivery; outbound: MX records, connected host, remote reply, retries) and the hops of the stored original.

## Fixed

- **Retention policies** now work as documented: correct precedence between several policies, scoped legacy policies, inherited folder tags, shared mailboxes included, 30-day recovery window, permanent deletes through the message store. See the CHANGELOG for the full list.
- **HTTPS status in "Protokolle und Dienste"** reflects the certificate the HTTPS server actually serves; no false MAPI HTTPS warning.

## Upgrade

```bash
cd /opt/coremail && git pull && docker compose pull && docker compose up -d
```

- The search index is created once at start; writes to `messages` wait for it (about 22 s for 2 million messages). If the database role may not create the `pg_trgm` extension, CoreMail starts without the index and logs the command to enable it (docs/search.md).
- **Retention:** the first run after the update may remove mail the old run left alone (shared mailboxes under a global or domain policy, folders with a personal tag of users without a policy, subfolders of default folders with a retention tag). Review your policies before upgrading.

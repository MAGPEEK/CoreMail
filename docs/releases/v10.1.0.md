# CoreMail v10.1.0: new compose area

**Image:** `magpeek/coremail-app:10.1.0` · **Helm chart:** 3.1.0 · **Date:** 2026-11-19 · **Predecessor:** v10.0.0

A minor release: upgrade from 10.0.0 without configuration changes; no schema change.

## Changed

- **Compose area redesigned.** The inline compose is a raised card on the tinted reading pane (the own window and phone widths keep the same layout without margin and shadow).
- **"Senden" is a split button at the top left** and the only accent-filled control. Its chevron (or Alt+Pfeil-unten) opens Senden, Später senden, Wichtigkeit and Nachrichtenoptionen. Attach, picture and signature are quiet icons, everything else is in the "…" menu; the bottom action bar is gone.
- **Right edge of the header:** draft status ("Entwurf gespeichert 10:42"), open in a new window, Verwerfen and a close button ("Schließen — Entwurf bleibt erhalten").
- **Calmer fields:** 36 px address rows, recipient chips with avatar or profile photo, Cc/Bcc as links in the To row, a larger subject line.
- **Easier reading:** 15 px text, line height 1.6, at most 72 characters per line.
- **Formatting bar at the bottom of the card** (now also with Link and Emoji). It can be hidden ("Aa" or "Formatleiste ausblenden"); the choice is a roaming personal setting (`compose.composeFormatBar`, default on).

## Upgrade

```bash
cd /opt/coremail && git pull && docker compose pull && docker compose up -d
```

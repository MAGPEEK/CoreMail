# CoreMail v10.6.1: Let's Encrypt fix

**Image:** `magpeek/coremail-app:10.6.1` · **Helm chart:** 3.6.1 · **Date:** 2026-11-21 · **Predecessor:** v10.6.0

A patch release: no configuration or schema change.

## Fixed

- **Let's Encrypt certificates can be ordered again.** In 10.6.0 the setup wizard step "Zertifikat" and BCP → SSL/TLS failed with "Cannot get schema for 'AlgorithmIdentifier' target". Two copies of the certificate libraries were loaded side by side since passkeys arrived; the build now uses one copy, and a test guards against it.

## Update

```bash
curl -fsSLO https://github.com/MAGPEEK/CoreMail/releases/latest/download/docker-compose.yml
docker compose pull && docker compose up -d
```

Then choose "Erneut prüfen" in the setup wizard, or order the certificate in BCP → SSL/TLS.

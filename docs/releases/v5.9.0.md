# CoreMail v5.9.0 — English repository + v5.8.0 features (Admin CLI, new Docker Compose, EWS tied to MAPI)

**Image:** `magpeek/coremail-app:5.9.0` · **Date:** 2026-10-28 · **Predecessor:** v5.7.1 (JMAP server)

## Highlights

The whole repository is now English: README, CHANGELOG, CLAUDE.md, the docs, code and infra comments, and the CLI output. The German README is kept as `README.de.md`. This release also ships the v5.8.0 features, which were never published as a separate image:

- **Admin CLI `coremail`** — users, mailboxes, Shared Mailboxes, connectors, SMTP banner and certificates from the command line, scriptable with `--json` (see [docs/cli.md](../cli.md)).
- **New `docker-compose.yml`** — reduced to the essentials; five required `.env` values checked at startup, `bash scripts/setup.sh` generates them.
- **EWS tied to MAPI over HTTP** — one switch in the BCP (Server → "MAPI over HTTP + EWS", default off); `/EWS/*` and `/OAB/*` return 404 while it is off.

Details: [v5.8.0 release notes](v5.8.0.md).

## Image

`magpeek/coremail-app:5.9.0`

## Upgrade

```bash
cd /opt/coremail && docker compose pull coremail && docker compose up -d coremail
```

- No schema change; no data loss.
- The existing `.env` remains valid.

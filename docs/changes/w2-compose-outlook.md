# w2-compose-outlook — changelog text (webmail compose)

SemVer: MINOR. Webmail UI plus additive server changes: `Message.importance` (new nullable column,
schema-sync applies it without data loss), drafts and `POST /mail/send` take an optional
`importance`, `POST /mail/drafts/:id/send` and `/mail/send` an optional `requestDeliveryReceipt`,
`GET /mail/drafts/:id` returns `importance`. No config or CLI change; existing requests behave as
before. The webmail route `/compose/<draftId>` is new.

### Added
- Webmail: new mails, replies, reply-all, forwards and "Entwurf bearbeiten" open in the reading
  pane instead of a floating box (reading pane off: in place of the message list; below 768 px full
  screen). Several drafts can be open: a tab strip at the bottom of the mail view switches between
  them (opening a mail in the list puts the shown draft into the strip, ✕ on a tab saves and closes
  it); every draft keeps its fields, attachments and autosave across switches.
- Webmail: "In neuem Fenster öffnen" moves a draft into a browser window of its own
  (`/compose/<draftId>`, loads the server draft). Sending there hands the mail to the main window
  (undo toast there); closing the window saves and returns the draft to the tab strip; closing the
  browser window with unsaved changes asks first. A draft of a shared or delegated mailbox keeps
  that mailbox in its window (sender choice and signature swap as inline).
- Webmail compose: command row with **Senden** (split: Senden / Senden planen …), **Verwerfen**,
  **Anhängen** (Datei / Bild) and "…" (Signatur, Lesebestätigung anfordern, Nur-Text-Format, Als
  Entwurf speichern, In neuem Fenster öffnen), ✕ to save and close.
- Webmail compose: ribbon with the tabs **Nachricht**, **Einfügen** and **Format** — font size,
  emoji picker, insert picture (also by pasting; raster images up to 500 KB), insert date/time in
  the regional format, link dialog with "Link entfernen", font / highlight colours by name.
- Webmail compose: recipients as pills with suggestions (click shows the full address, ✕ or
  Backspace removes one, pasted lists are split, invalid addresses are marked and stop the send
  before the server is asked); "Cc" / "Bcc" buttons right of the An row.
- Webmail compose: replies and forwards quote the original below a separator with Von / Gesendet /
  An / Cc / Betreff; a long reply quote is folded behind "…" (still sent).
- Webmail compose: files dropped anywhere on the compose area are attached (max. 10, the server
  limit); plain-text format can be switched per mail; "Entwurf gespeichert um HH:MM" above the body.
- Webmail: Esc saves the draft and closes it (asks only when it cannot be saved); the shortcut help
  lists Esc, Ctrl+B and Ctrl+I of the compose area.
- Webmail compose: "…" → **Wichtigkeit** (hoch / normal / niedrig) — stored in the draft and sent as
  `Importance` / `X-Priority`; the reader shows "Wichtigkeit: hoch / niedrig" for mails that carry
  such a header (stored at delivery as `Message.importance`); inbox rules with the condition
  "Wichtigkeit" now see the real value (it was always "normal"), and the rule action "Wichtigkeit
  setzen" — offered before but never applied — now sets the stored importance at delivery and on
  "Jetzt auf Posteingang anwenden".
- Webmail compose: "…" → **Übermittlungsbestätigung anfordern** — a delivery status notification per
  recipient (NOTIFY=SUCCESS,FAILURE; local deliveries are reported by the server itself).
- Webmail compose: **Einfügen → Tabelle** — insert a table, add rows / columns before or after,
  delete row / column / table; tables carry inline styles so other mail clients show the grid, and
  tables of a quoted original are kept.
- Webmail compose: a larger font list grouped by script (Latin, Chinese/Japanese/Korean, other
  scripts), each name shown in its own font and written as a CSS font stack with open fallbacks;
  sizes 8–36 pt. New text starts with the font and size of Settings → Verfassen (same lists), else
  Calibri 11 pt.
- Webmail: opening a draft that is already open in its own window brings that window to the front
  instead of opening it a second time inline.
- Webmail Settings: the navigation entry "Gelöschte Elemente" is shown as a sub-entry of "Speicher".

### Changed
- Webmail: the floating compose window (bottom right, minimise bar) is removed.
- Webmail: a mail reopened after "undo send" while another mail is being written opens in the
  draft tab strip instead of waiting until that window is closed; `n` / Ctrl+N also start a new mail
  while one is open (the open one goes to the strip), and switch to Mail when pressed on another page.
- Webmail: menus of the command bars show toggles as checkable entries (`menuitemcheckbox`).

### Fixed
- Mail generated by the server (drafts, Sent copies, outgoing mail, calendar invitations) had bare
  LF line ends: nodemailer has no `crlf` newline option. It now uses CRLF throughout.
- Webmail / REST send: recipients picked from the suggestions ("Name <a@b>") were used as SMTP
  envelope addresses — local mailboxes were not recognised as local. The envelope now carries the
  bare addresses, each once.
- Webmail own compose window: a send handed to a main window that had been reloaded was dropped
  (the window closed, the mail stayed a draft); it is now confirmed by the main window, else the
  window sends itself. Reloading the window after a save loaded an outdated draft id ("Entwurf nicht
  gefunden"); the address now follows the current version.
- Webmail: a draft over the size limit reported only "nicht gespeichert"; the message now names the
  limit and asks to remove or shrink attachments.
- Webmail: the forgotten-attachment check counted text after a nested quote inside a quoted reply
  chain as newly written.
- Webmail: reply all kept only the sender and the original Cc — the original An recipients were
  dropped. It now addresses the sender + the original An (Cc: the original Cc) without the user's
  own address or the mailbox composed in; a reply to an own sent mail goes to its recipients.
- Webmail: after a page reload the compose did not know the user's own address (sender label,
  reply-all lists); it is read from the profile when the session has none.

### Added
- Search suggestions from the whole mailbox while typing: `GET /api/v1/mail/search/suggest?q=` (2–100 characters) and the same route of shared / delegated mailboxes return up to 4 people (senders, recipients of the newest 2 000 Sent messages, own contacts while the contacts module is on — de-duplicated) and up to 6 messages (subject / sender match, newest first, never bodies) with folder name and date. Foreign mailboxes cover exactly the folders their `/search` covers (`canReadFolder`). Per-user rate limit 120 requests / 60 s (`MAIL_SUGGEST_RATE_LIMIT`, `MAIL_SUGGEST_RATE_WINDOW_SEC`; 429 `RATE_LIMITED`). `lib/search-suggest.ts`, docs/search.md.
- Trigram index `messages_search_trgm_idx` (PostgreSQL `pg_trgm`, GIN over `subject`, `fromName`, `fromAddr`; Prisma preview feature `postgresqlExtensions`). PostgreSQL keeps it current on every write — no indexing job. It serves the suggestions and the subject / sender conditions of `/mail/search`. Measured on a 100 000-message mailbox (2 million messages in the table): rare terms 0.2–1 ms per query instead of 60–100 ms; very common terms cost about as before (docs/search.md).
- Webmail: the message list search and the header search ("Suchen…") show a suggestion dropdown — **Personen** (picks run `from:<address>` over the whole mailbox — the list's scope switch changes to "Alle"), **Nachrichten** (open the message through its deep link) and, for an empty focused field, **Letzte Suchen** (last 5 terms per user in this browser, removable with "×" or Delete). 150 ms debounce, stale requests aborted, previous suggestions kept while loading; ↑/↓, Enter, Escape (combobox with `aria-activedescendant`). Operator syntax keeps the plain full search without suggestions.
- schema-sync: an *optional* extension (`OPTIONAL_EXTENSIONS` in `schema-sync-classify.mjs`, today `pg_trgm`) the database cannot provide — e.g. the least-privilege app role `coremail_app` without `CREATE` on the database — no longer stops the start: the schema is pushed once more without the lines tagged `// schema-sync:optional pg_trgm` (the extension entry and the index) and a warning explains `CREATE EXTENSION pg_trgm`; the next start applies the full schema.

### Changed
- Webmail: the message list's local typeahead (hints only from the loaded page) is replaced by the server suggestions. `api.get()` accepts an `AbortSignal`.

Upgrade: `prisma db push` creates the extension (when missing) and the index — no data-loss warning, no dump; building the index blocks writes to `messages` for its duration at start (≈ 11 µs per message: 22 s for 2 million). Databases created by `init.sql` / the Helm chart already have `pg_trgm`. Additive: new endpoint, new index, no breaking change (MINOR).
